## Things That Will Bite You

- **ROADMAP is the authority on phase status, not the file count.** After 03-01 and 03-02, the
  PLAN/SUMMARY counts matched and would have falsely signalled "phase complete" — because later
  plans simply had not been written yet. That false signal was correctly ignored twice.
- **Never read an exit code through a pipe.** `cmd | tail` gives you `tail`'s status. This has
  produced a wrong conclusion three times in this project.
- **Grep for absence must strip comments first**, and must include a positive control. An audit
  that reports zero hits in *every* file — including the one that definitely contains the thing —
  is proving nothing.
- **Which scope filter is load-bearing must be measured per query shape.** For `getCarReport` the
  `getCarById` pre-check did all the isolation work and the relation filter none. For
  `getFleetSummary` the two filters are redundant with each other. Same question, opposite
  answers — mutation-test each new query rather than carrying a conclusion across.
- **Vitest does not type-check; `next build` does.** Run both.
- **Verify e2e with `CI=true`**, or `reuseExistingServer` may quietly reuse a stale dev server.
